# Todas tus IAs en un mismo chat.

**ZM no es otra IA.** Es una app que corre en tu computadora y junta a las IAs que ya usas (Codex, Claude Code, Gemini, Cursor y OpenCode) en un solo chat, dentro de tu proyecto. Les escribes con tus palabras, cada una lee lo que dijeron las otras y tú decides qué pueden cambiar. Lo que se decide queda guardado.

**Basado en MADRE by Jossue Alcalá — https://madre.run**

## Instálala

**macOS y Linux.** Abre la Terminal y escribe:

```
npx @zarzmra/zm
```

Necesitas Node 22.5 o más nuevo y al menos una IA con sesión. No hay cuenta que crear. ZM se abre en tu navegador y una bienvenida te guía paso a paso.
