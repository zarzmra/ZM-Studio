# ZM Studio · Todos tus asistentes de IA en un mismo lugar.

**ZM Studio es una plataforma de colaboración que integra tus herramientas de IA favoritas en un único espacio de trabajo.**

Trabaja con Codex, Claude Code, Gemini CLI y OpenCode simultáneamente en tu proyecto. Todos comparten una memoria compartida que ves y controlas. Decides qué puede cambiar cada uno. Todo lo que ocurre queda registrado en tu máquina.

## Características principales

- **Integración unificada** - Accede a múltiples asistentes desde una sola interfaz
- **Memoria compartida** - Los agentes ven el contexto del proyecto y aprenden de cada turno
- **Control total** - Modo de solo lectura por defecto, con permisos granulares por mensaje
- **100% local** - Nada sale de tu máquina sin tu permiso
- **Historial auditable** - Cada decisión, cambio y permiso queda registrado

## Instalación

**macOS, Linux y Windows (WSL2).**

```bash
npx @zmstudio/app
```

Requiere Node.js 22.5 o superior y al menos un asistente de IA configurado. No hay cuentas que crear. ZM Studio se abre en tu navegador con una guía paso a paso.

## Cómo funciona

1. Conecta tus asistentes de IA (Codex, Claude Code, etc.)
2. Abre un proyecto en ZM Studio
3. Escribe instrucciones en lenguaje natural
4. Los asistentes proponen cambios
5. Aprueba, rechaza o modifica cada cambio
6. El historial se mantiene en tu máquina

## Requisitos de licencia

**Gratis para personas y equipos de hasta 10 miembros** - incluso si lo usas para trabajo de clientes.

Para organizaciones más grandes o para ofrecer ZM Studio como servicio, se requiere una licencia comercial.
